# My First Blog Post

Welcome to my blog. This is a simple markdown-powered setup — drop a `.md` file into `/blogs/` and it becomes a post at `#/blogs/<filename>`.

## Why Markdown?

Markdown keeps the writing friction low. No CMS, no database, no build step. Just a file.
